The one question behind every metric choice

Which mistake is worse here: a False Negative or a False Positive? Once you answer that, the metric almost chooses itself.

Your toolkit

Truth: Positive Truth: Negative
Predicted Positive TP FP
Negative FN TN
Metric Formula The question it answers
Accuracy \(\frac{TP+TN}{\text{Total}}\) How often is the model right overall?
Recall (Sensitivity) \(\frac{TP}{TP+FN}\) Of all real positives, how many did we catch?
Precision \(\frac{TP}{TP+FP}\) Of everything we flagged, how much was real?
Specificity \(\frac{TN}{TN+FP}\) Of all real negatives, how many did we correctly clear?
F1-Score \(\frac{2 \cdot P \cdot R}{P+R}\) One number that balances Precision and Recall

Step zero: always name the positive class first. FN and FP mean nothing until you know what “positive” is.

Question 3: Which metric?

Q3 | Model A, Scenario A

MODEL A
A maintenance model needs to catch real equipment failures and avoid too many false alarms. Management wants one balanced score to compare different versions of the model over time.

Hint

“Catch real failures” worries about one error. “Avoid false alarms” worries about the other. Is there one number that balances both?

Show answer

F1-Score   Balance FN and FP

  • “Catch real failures” = reduce FN = Recall
  • “Avoid false alarms” = reduce FP = Precision
  • “One balanced score” = the harmonic mean of the two = F1

Why not Accuracy? Accuracy also gives one number, but failures are usually rare. A model that predicts “no failure” every time can still score high Accuracy while catching nothing. F1 ignores TN, so it cannot be inflated that way.

Q3 | Model A, Scenario B

MODEL A
A model checks medicine packages for bad seals before shipping. If it misses a bad seal, contaminated medicine could reach a patient.

Hint

Positive = bad seal. “Misses a bad seal” means it was truly bad but predicted good. Which cell is that?

Show answer

Recall   Minimize FN

  • Missed bad seal = FN, and the consequence is patient harm.
  • A false alarm (FP) only costs a re-check of a good package.
  • We want to catch every bad seal, even if it means some extra false alarms: \(\text{Recall} = \frac{TP}{TP+FN}\)

Keyword cue: “misses”, “slips through”, “reaches the patient/customer” → Recall.

Q3 | Model A, Scenario C

MODEL A
A model screens incoming raw material batches for contamination before they enter the production line. If a batch is wrongly flagged as contaminated, the whole batch is destroyed. The plant wants to be confident that batches it clears as safe are truly safe.

Hint

Positive = contaminated. The costly event described is a safe batch being flagged. Which group of batches are we trying to protect: the flagged pile, or all the truly safe batches?

Show answer

Specificity   Minimize FP among true negatives

  • Safe batch wrongly flagged = FP, and the consequence is destroying a good batch.
  • We want the model to correctly clear as many truly safe batches as possible: \(\text{Specificity} = \frac{TN}{TN+FP}\)

Why not Precision? Both punish FP, but they look at different groups:

  • Precision looks at the flagged pile: of what we flagged, how much was real? Use it when flags consume limited resources (review time, inspectors).
  • Specificity looks at all real negatives: of all the good items, how many did we leave alone? Use it when the concern is good items being wrongly punished (destroyed, reworked).

Q3 | Model A, Scenario D

MODEL A
A factory wants one simple number for a monthly report. The two outcomes (pass/fail) happen about equally often, and neither type of mistake is worse than the other.

Hint

Two conditions are given: are the classes balanced? Are the costs equal? If both are yes, do we need anything fancier?

Show answer

Accuracy   FN and FP equally bad

  • Classes are balanced, so Accuracy is not inflated by a majority class.
  • Costs are equal, so there is no reason to favor FN or FP.
  • The audience wants one simple number: \(\text{Accuracy} = \frac{TP+TN}{\text{Total}}\)

Keyword cue: Accuracy is the right answer only when you see balanced classes + equal costs. If either is missing, look elsewhere.

Q3 | Model A, Scenario E

MODEL A
A model flags “suspicious” transactions for a review team to check by hand. The team can only check a small number each day, so too many wrong flags wastes their time.

Hint

The bottleneck is the review team. Every flag uses up their time. What do we want to be true about the things we flag?

Show answer

Precision   Minimize FP in the flagged pile

  • Wrong flag = FP, and the consequence is wasted reviewer time.
  • With limited capacity, we need each flag to be worth checking: \(\text{Precision} = \frac{TP}{TP+FP}\)

Keyword cue: “limited capacity”, “can only check a few”, “wastes their time” → Precision.

Q3 | Model B, Scenario D

MODEL B
A model screens finished products for scratches before they are approved for sale. If a scratch-free product is wrongly flagged as scratched, it is needlessly reworked. The team wants to be confident that products it clears as scratch-free are truly scratch-free.

Hint

Positive = scratched. The costly event is a good product being flagged. Are we protecting the flagged pile, or all the truly good products?

Show answer

Specificity   Minimize FP among true negatives

  • Scratch-free product flagged as scratched = FP, and the consequence is needless rework of a good product.
  • We want to correctly clear as many truly scratch-free products as possible: \(\text{Specificity} = \frac{TN}{TN+FP}\)

Why not Precision? There is no limited review team here. The concern is good products being punished, so we look at all real negatives, not the flagged pile.

Q3 | Model B, Scenario E

MODEL B
A predictive-maintenance model needs to catch real motor failures and avoid too many unnecessary shutdowns. Management wants one balanced score to compare different versions of the model over time.

Hint

Two worries joined by “and”, plus “one balanced score”.

Show answer

F1-Score   Balance FN and FP

  • “Catch real failures” = Recall; “avoid unnecessary shutdowns” = Precision.
  • “One balanced score” = \(F_1 = \frac{2 \cdot P \cdot R}{P+R}\)

Why not Accuracy? Motor failures are rare, so Accuracy can look great while missing most failures.

Where points were lost

Common mistakes

  1. Mixing up Precision and Specificity

Both reduce FP. Ask Which matters more:

  • Avoiding false alarms on the positive class → Precision
  • Avoiding missing the true negative → Specificity
  1. Choosing Accuracy whenever you see “one number”

“One number” alone is not enough. Accuracy needs balanced classes AND equal costs. If the scenario mentions two competing errors (“catch failures and avoid false alarms”), the one number is F1.

  1. Not fixing the positive class first

FN and FP flip if you flip the positive class. Always write “Positive = ___” before labeling any error.

  1. Justification that does not name the error

“Recall is better” earns little credit. A full justification has three parts: the error (FN or FP), why it is worse (cost or consequence), and the metric that targets it.
