Regularization

Ridge

\[\begin{eqnarray} T^{arget}&=&\frac{1}{20}\sum_{i=1}^{20} \left ( \widehat{Price}_i-Price_i\right)^2+\lambda P^{enalty} \\ \mbox{with:}&& \widehat{Price}_i=\beta_1 Sqft_i+\beta_2 Sqft_i^2+\beta_3 Sqft_i^3+\beta_4 Sqft_i^4+\beta_5 Sqft_i^5+\beta_6 \nonumber \\ \mbox{with:}&& P^{enalty}=\sum_{j=1}^{5} \beta_j^2 \nonumber \end{eqnarray}\]

Two Goals: Minimize \(MSE\) and Minimize Penalty (small or zero \(\beta s\))

\(T^{arget}\) value still only depends on data and \(\beta s\).

Note, when reducing a large and a small parameter by the same amount, the impact of reducing the large parameter has a bigger impact on the penalty than reducing the small parameter. Thus. Ridge has a tendency to reduce large rather than small parameters

Regularization

Lasso

\[\begin{eqnarray} T^{arget}&=&\frac{1}{20}\sum_{i=1}^{20} \left ( \widehat{Price}_i-Price_i\right)^2+\lambda P^{enalty} \\ \mbox{with:}&& \widehat{Price}_i=\beta_1 Sqft_i+\beta_2 Sqft_i^2+\beta_3 Sqft_i^3+\beta_4 Sqft_i^4+\beta_5 Sqft_i^5+\beta_6 \nonumber \\ \mbox{with:}&& P^{enalty}=\sum_{j=1}^{5} | \beta_j | \nonumber \end{eqnarray}\]

Two Goals: Minimize \(MSE\) and Minimize Penalty (small or zero \(\beta s\))

\(T^{arget}\) value still only depends on data and \(\beta s\).

Note, reducing a large or a small \(\beta\) parameter by the same amount has the same impact on the penalty. Thus Lasso would always reduce the parameter where the reduction has the smallest impact on the \(MSE\). Some parameters might be reduced to zero

Comparing Parameter Reduction for Different Penalties

Ridge:

Shrinkage of Parameters \(\beta s\) for Increasing Penalty Factors (\(\lambda\))

Lasso:

Shrinkage of Parameters \(\beta s\) for Increasing Penalty Factors (\(\lambda\))

Elastic Net

\[\begin{equation} T^{arget}_{Elastic} = \underbrace{\frac{1}{20}\sum_{i=1}^{20}\left(\widehat{Price}_i-Price_i\right)^2}_{MSE} + \lambda\overbrace{\left(\alpha P^{enalty}_{Lasso} + (1-\alpha) P^{enalty}_{Ridge}\right)}^{P^{enalty}_{Elastic}} \end{equation}\]

with:

\[\begin{equation} \widehat{Price}_i = \beta_1 Sqft_i+\beta_2 Sqft_i^2+\beta_3 Sqft_i^3+\beta_4 Sqft_i^4+\beta_5 Sqft_i^5+\beta_6 \end{equation}\] \[\begin{equation} T^{arget}_{Elastic} = \underbrace{\frac{1}{20}\sum_{i=1}^{20}\left(\widehat{Price}_i-Price_i\right)^2}_{MSE} + \lambda\overbrace{\left(\underbrace{\alpha\sum_{j=1}^{5}|\beta_j|}_{P^{enalty}_{Lasso}} + \underbrace{(1-\alpha)\sum_{j=1}^{5}\beta_j^2}_{P^{enalty}_{Ridge}}\right)}^{P^{enalty}_{Elastic}} \end{equation}\]

Specify a Tunable Model

Code 
ModelTune = linear_reg(penalty = tune(), mixture = tune()) |>
  set_engine("glmnet") |> set_mode("regression")

tune() is a placeholder; we haven’t picked penalty or mixture values yet.

Build the Workflow

Code 
WFTune = workflow() |> add_recipe(RecipeHouses) |> add_model(ModelTune)

Create Resampling Folds

Code 
set.seed(777)
Folds = vfold_cv(DataTrain, v = 3)

Cross-validation happens entirely inside the training data. The test set stays untouched until the very end.

Define the Candidate Values

Code 
PenaltyGrid = penalty(range = c(1, 7))      # log10 scale: 10 to 10,000,000
MixtureGrid = mixture(range = c(0, 1))      # 0 = Ridge, 1 = Lasso

Build the Full Tuning Grid

Code 
Grid = grid_regular(PenaltyGrid, MixtureGrid, levels = c(penalty = 7, mixture = 4))
